
### 4-3. 함수 명세표
| 함수/객체 | 위치 | 입력 | 출력/효과 |
|---|---|---|---|
| get_db() | database.py | — | 요청 단위 DB 세션 제공(yield), 종료 시 자동 close |
| User/LoginSession/Category/Contact | models.py | — | 테이블 정의(Mapped 문법) |
| SignupIn/ContactCreate/ContactUpdate 등 | schemas.py | — | 입출력 양식+검증 규칙 |
| hash_password(원문) | security.py | 원문 | Argon2 해시 |
| verify_password(원문, 해시) | security.py | 입력값, 저장 해시 | True/False |
| create_user(db, data) | crud.py | SignupIn | User INSERT+기본 카테고리 3개(단일 트랜잭션) |
| authenticate_user(db, username, password) | crud.py | 로그인 입력 | 성공 시 User, 실패 시 None |
| create_login_session(db, user_id) | crud.py | user_id | 세션 토큰 생성+sessions INSERT→토큰 반환 |
| get_current_user(session_id, db) | routers/auth.py | 쿠키 session_id | User 반환 또는 401 raise |
| delete_login_session(db, session_id) | crud.py | session_id | sessions DELETE |
| list_contacts(db, user_id, name, category_id) | crud.py | 검색조건 | 내 연락처 목록(필터 적용) |
| get_my_contact(db, user_id, contact_id) | crud.py | 대상 id | `WHERE id=? AND user_id=?` → Contact 또는 None |
| create_contact/update_contact/delete_contact | crud.py | 대상+데이터 | INSERT/UPDATE/DELETE+commit |
| **phone_exists(db, user_id, phone, exclude_id=None)** | crud.py | 전화번호+제외id | 내 범위 중복 여부(bool), 수정 시 자기 자신 제외 |
| count_contacts_in_category(db, user_id, category_id) | crud.py | 카테고리 id | 소속 연락처 수(삭제 전 필수 확인) |
| **category_name_exists(db, user_id, name, exclude_id=None)** | crud.py | 카테고리명+제외id | 내 범위 중복 여부(bool), 수정 시 자기 자신 제외 |
| 라우터 함수 12개 | routers/*.py | HTTP 요청 | 인증확인→검증→crud호출→상태코드 결정 |

> ⚠️ **`exclude_id` 파라미터 신규 추가 (v1.0의 숨은 버그 수정)**: v1.0의 함수 명세에는 `phone_exists`, `category_name_exists`에 자기 자신을 제외하는 파라미터가 없었습니다. 이 상태로 구현하면 "연락처 A의 주소만 수정하려고 phone 필드를 그대로 다시 전송했는데 409(중복)가 뜨는" 버그가 발생합니다 — 실제로 매우 흔한 실수입니다. §7-2, §9-3에 구체적인 코드를 반영했습니다.
