### 1-1. 버전 호환성 검증

동일 venv에 전 구성요소를 설치하여 실제 실행으로 충돌 여부를 검증했다. 1차 과제는 표준 라이브러리만 사용했으나, 2차 과제는 외부 패키지 7종으로 버전 관리 전략이 필수다.

| 점검 항목 | 결과 |
|---|---|
| 외부 패키지 의존성 | 있음(7개) — 1차 대비 최대 차이점 |
| requirements.txt | 필요(버전 고정) |
| 가상환경(venv) | 필수 |
| FastAPI↔Pydantic 궁합 | FastAPI 0.139.0은 Pydantic v2 계열 필요 |
| SQLAlchemy↔psycopg | 접속 문자열 `postgresql+psycopg://` 명시 필요 |
| pwdlib[argon2] | `pip install "pwdlib[argon2]"` extras 지정 필요 |

```
# requirements.txt
fastapi==0.139.0
uvicorn[standard]==0.50.0
pydantic==2.13.4
sqlalchemy==2.0.51
psycopg[binary]==3.3.4
pwdlib[argon2]==0.3.0
python-multipart==0.0.7

# 설치
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```
