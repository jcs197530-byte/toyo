## 11. 디렉터리 구조 및 실행

```
contact_app/
├── main.py, database.py, models.py, schemas.py, security.py, crud.py
├── routers/{__init__.py, auth.py, contacts.py, categories.py}
├── static/{index.html, app.js}
├── requirements.txt
├── docker-compose.yml   # PostgreSQL 16(pg-lab)
├── .env                 # DATABASE_URL 등(git 제외)
└── README.md
```

```
# 실행 절차
1) docker compose up -d
2) python -m venv venv && source venv/bin/activate
3) pip install -r requirements.txt
4) uvicorn main:app --reload    # http://127.0.0.1:8000
5) http://127.0.0.1:8000/docs   # Swagger UI 검증
```
